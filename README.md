## FlClash_CC

> update 260529: The original project brought back colored icons, but the new design isn't my favorite—they're too small and hard to read. I changed them back to the old ones. Depending on the original project updates, I might stop maintaining this repo in the future.

CC, which means Color Changed. Forked from the original author's [project]("https://github.com/chen08209/FlClash").

The original project removes the icon color change feature because it may cause other problems.

If you want to support it, please support the original author.
